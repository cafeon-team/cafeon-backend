CafeOn 리뷰 사진 API 변경사항 (2026-08-20)

1. 사진 업로드

POST /api/uploads/images
Authorization: Bearer {customer_token}
Content-Type: multipart/form-data
필드명: image

응답의 url을 리뷰 요청의 image_urls에 사용합니다. 업로드한 사용자 ID와 파일
경로가 서버에 기록되므로 다른 사용자가 업로드한 URL이나 외부 URL은 사용할 수
없습니다.

2. 리뷰 등록

POST /api/stores/{store_id}/reviews

{
  "customer_visit_id": 1,
  "rating": 5,
  "content": "리뷰 내용",
  "image_urls": [
    "http://192.168.0.75:8000/storage/blog/example.jpg"
  ]
}

image_urls는 최대 5개이며 중복 URL은 허용되지 않습니다. 본인 토큰으로 먼저
업로드한 CafeOn 파일만 첨부할 수 있습니다.

3. 리뷰 사진 조회

GET /api/stores/{store_id}/reviews

각 data 항목의 images 배열에서 image_url을 읽어 카페 상세의 사진 탭에
표시합니다. 리뷰 사진을 브라우저 localStorage에 별도로 보관할 필요가 없습니다.

4. 리뷰 수정·삭제

PUT /api/reviews/{review_id} 요청에 image_urls 전체 목록을 보내면 그 목록으로
교체됩니다. 제외된 기존 사진은 DB와 실제 storage 파일에서 삭제됩니다.

DELETE /api/reviews/{review_id}를 호출하면 리뷰는 soft delete되고 연결된
review_images 레코드와 실제 storage 이미지 파일은 함께 정리됩니다.

5. 오류

- 401: 로그인 토큰 없음 또는 만료
- 403: 다른 사용자의 리뷰 수정·삭제 시도
- 422 image_urls.N: 외부 URL, 다른 사용자 파일, 삭제·누락된 파일 또는 이미
  다른 리뷰에 연결된 파일

Swagger에도 업로드 multipart 형식, image_urls 요청, images 응답 구조가
반영되어 있습니다.
